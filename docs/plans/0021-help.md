**Goal:** a press of `H` opens the help — a framed box over the game with seven rows, a key
and what it does — and a second press closes it; the game stands still while it is open; for
the first ten seconds of a game one line at the bottom names the key.

**Approach:** four code tasks, each green on its own. The words (T1). The state and the rules
(T2): the game's input gains `help`, the state the boolean `help`; `game/help` opens and
closes; `update` gains the help's step, before the journal's. After T2 the key works and the
game stands still, but nothing is drawn — a press of `H` looks like a frozen game until T3.
The box and the start hint (T3): `render/draw-help`, drawn by the scene over whatever it
draws, and the hint in the notice's bar. The smoke spec (T4). Then the documents (T5), the
full check with the container (T6), the walk (T7) and the pull request (T8).

## Global constraints

- INV-1: `GameState.help` is a boolean. The rows of the box and whether the start hint shows
  are **not** in the state: the rows are constants of `render/draw-help`, and the hint is
  derived from `tick` in every frame.
- INV-2: `src/game/help.ts` imports nothing from `src/render/`, uses no DOM name and not the
  type `Language`. `src/render/draw-help.ts` may import from `game/` but needs nothing of it.
- INV-4: every word of the help lives in `src/text/de.ts` and `src/text/en.ts`, the letters of
  the keys too; `drawText` stays the only function that draws text.
- The order of a step in `update`: the dark; the help open; a press of `help`; the journal
  open; a dialogue open; a press of `journal`; a press of `talk`; the ordinary step.
- With the help open, `update` returns the state with `tick`, `held` and `help` changed and
  nothing else. Opening changes nothing else either — not the dialogue, not the journal, not
  the lamp, not a push, not the player's frame.
- `help` does nothing in the dark. The dark's step sets `held`, as it does since 0020.
- The scene draws the help **after** everything else and **before** the lids of the dark, and
  after the journal when the journal is open. With the help open the bar shows neither the
  language line nor the start hint; the notice and the dialogue box are drawn as the state has
  them.
- The bar's order: the dialogue box, then the notice, then the language line, then the start
  hint. With the journal open the scene draws no bar at all.
- `draw-help.ts` imports nothing from `draw-scene.ts`; `draw-scene.ts` imports `drawHelp`.
- `engine/input` is **not** changed. No tile changes, no map changes, no new sprite, no new
  colour. `window.shadowAi` is unchanged.
- The game reads the held keys once per frame: a key that goes down and up within one frame
  is not seen. That is why the smoke test holds a key until the state shows it. Do not change
  the input for it.
- No `any`, no `@ts-ignore`. Commits: imperative subject, a body that says why, signed (run
  `git commit` outside the sandbox), ending with the attribution line the session's own
  reminder names — for Opus, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  Format with `npx biome check --write <files>` before `npm run check`.
- The numbers, verbatim from the spec: `help` ← `KeyH`; `HELP_HINT_STEPS` is 600; the hint is
  the key `notice.help` in the bar (8, 158, 304, 18), a line of n characters from
  (160 − 3n, 162) — German from (118, 162), English from (121, 162); the frame is the
  rectangle (48, 30, 224, 98) in `#3a4466`, the field (49, 31, 222, 96) in `#181425`; row k
  has its key from (56, 38 + 12k) and what it does from (170, 38 + 12k); a key has at most 17
  characters, what it does at most 16; the seven rows are walk, lamp, talk, journal, language,
  fullscreen, help.

```ts
import { type TextKey, textKey } from '../text/text';
import { type GameInput, pressed } from './player';
import type { GameState } from './state';

/**
 * The help (gameplay.md §8, feature 0021): a box over the game that lists every key. A press
 * of `help` opens it over whatever is there — the world, an open dialogue, the open journal —
 * and a press closes it. While it is open nothing is stepped: time passes, and that is all.
 * For the first seconds of a game one line names its key. Pure data and pure functions.
 */

/** The start hint: the line that names the key of the help. */
export const HELP_HINT: TextKey = textKey('notice.help');
/** Tune: ten seconds. */
export const HELP_HINT_STEPS = 600;

/**
 * Whether the start hint is due at `tick`: for the first HELP_HINT_STEPS steps of a game. The
 * tick grows in every step, so the time runs on behind an open help, dialogue or journal; the
 * scene decides what else has the bar first.
 */
export function helpHintDue(tick: number): boolean {
  return tick < HELP_HINT_STEPS;
}

/**
 * The state after a press that opens the help, or null when `help` is not pressed: the help
 * open, the tick grown, the input remembered. Nothing else changes, whatever else is open and
 * whatever else the input holds: a dialogue keeps its page, the journal its tab, and a figure
 * in mid-step, a push and a lamp that is on stay as they are.
 */
export function openHelp(state: GameState, input: GameInput): GameState | null {
  if (!pressed(state.held, input, 'help')) {
    return null;
  }
  return { ...state, tick: state.tick + 1, held: input, help: true };
}

/**
 * One step with the help open: the tick grows and the input is remembered. A press of `help`
 * closes it; the other keys do nothing. Nothing else changes.
 */
export function stepHelp(state: GameState, input: GameInput): GameState {
  return {
    ...state,
    tick: state.tick + 1,
    held: input,
    help: !pressed(state.held, input, 'help'),
  };
}
```

```ts
import type { Box, Point } from '../engine/tiled';
import { type Language, type TextKey, textKey } from '../text/text';
import { drawText } from './draw-text';
import { PAGE_BACKGROUND, type PaletteColour } from './palette';
import type { Renderer, SpriteSheet } from './renderer';

/**
 * The help (gameplay.md §8, visual.md §3, feature 0021): a framed box over whatever is on
 * screen, with one row per thing the player can do — the key, and what it does. It is drawn on
 * the surface, not shifted by the camera, in the language of the scene's settings. The rows
 * are what the box shows and no rule of the game reads them, so they live here.
 */

/** A row of the help: the name of the key, and what it does. */
export interface HelpRow {
  readonly key: TextKey;
  readonly does: TextKey;
}

/** The seven rows, in the order they are drawn. */
export const HELP_ROWS: readonly HelpRow[] = [
  { key: textKey('help.key-walk'), does: textKey('help.do-walk') },
  { key: textKey('help.key-lamp'), does: textKey('help.do-lamp') },
  { key: textKey('help.key-talk'), does: textKey('help.do-talk') },
  { key: textKey('help.key-journal'), does: textKey('help.do-journal') },
  { key: textKey('help.key-language'), does: textKey('help.do-language') },
  { key: textKey('help.key-fullscreen'), does: textKey('help.do-fullscreen') },
  { key: textKey('help.key-help'), does: textKey('help.do-help') },
];

/** The frame: it makes the box a box on the journal's screen, which has the field's colour. */
export const HELP_FRAME: Box = { x: 48, y: 30, width: 224, height: 98 };
export const HELP_FRAME_COLOUR: PaletteColour = '#3a4466';
/** The field inside the frame: 1 px of the frame is left on every side. */
export const HELP_FIELD: Box = { x: 49, y: 31, width: 222, height: 96 };
/** Where the key of row 0 starts, and where what it does starts; row k is HELP_ROW_PITCH × k lower. */
export const HELP_KEYS: Point = { x: 56, y: 38 };
export const HELP_DOES: Point = { x: 170, y: 38 };
export const HELP_ROW_PITCH = 12;
/** The longest name of a key and the longest text of what it does, in characters. */
export const HELP_KEY_CAPACITY = 17;
export const HELP_DOES_CAPACITY = 16;

export function drawHelp(renderer: Renderer, font: SpriteSheet, language: Language): void {
  renderer.fillRect(
    HELP_FRAME.x,
    HELP_FRAME.y,
    HELP_FRAME.width,
    HELP_FRAME.height,
    HELP_FRAME_COLOUR,
  );
  renderer.fillRect(
    HELP_FIELD.x,
    HELP_FIELD.y,
    HELP_FIELD.width,
    HELP_FIELD.height,
    PAGE_BACKGROUND,
  );
  for (const [k, row] of HELP_ROWS.entries()) {
    const down = k * HELP_ROW_PITCH;
    drawText(renderer, font, row.key, language, HELP_KEYS.x, HELP_KEYS.y + down);
    drawText(renderer, font, row.does, language, HELP_DOES.x, HELP_DOES.y + down);
  }
}
```
