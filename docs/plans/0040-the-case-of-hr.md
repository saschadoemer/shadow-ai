# 0040 — Implementation plan: the case of HR

**Spec:** [`docs/features/0040-the-case-of-hr.md`](../features/0040-the-case-of-hr.md)
(approved 2026-11-19). The plan argues from the spec; where they differ, the spec wins. Read
the spec first, then `CLAUDE.md`, then `docs/spec/world.md` §1 to §3, `docs/spec/gameplay.md`
§5 to §7, `docs/spec/architecture.md` §2 and §5 to §8, and `docs/spec/testing.md` §5.
**Written:** 2026-11-19 on the planning model. A working document, not specification.

**For the implementation session (Opus):** work task by task, test first, one commit per task,
`npm run check` green before every commit. Steps use checkboxes. When the spec and this plan
leave a question open, stop and ask the author — do not decide it with more tokens. The last
two tasks are the acceptance walk (`CLAUDE.md` §3.4) and the pull request (§3.5).

**The walk is new: you play it.** Since the commit `Let the agent play the acceptance walk` on
this branch, the agent plays the acceptance plan in a browser by simulated key presses
(`CLAUDE.md` §3.4, `docs/spec/testing.md` §5 — read both as they stand on this branch, not as
you remember them). Task 8 holds the walk's script. The feel questions stay with the author.
No pull request is opened before the walk has passed.

**Precondition:** feature 0038 is merged into `main` (`550c6e1`). The branch
`feature/0040-the-case-of-hr` exists, cut from that `main`. It holds the draft and the
approval of the spec, the commit that changes the walk, and this plan. Work on it; merge the
latest `main` into it before Task 1. `main` has moved since the branch was cut: `45116cb`
adds a promotional graphic and a longer `README.md`. It merges without a conflict; the
diff of the README in Task 6 then applies some fifty lines lower.

**Goal:** HR becomes the fourth case, the first behind the denser shadow. A colleague in a
yellow shirt walks in the room and is its source; three traces lie on the room's three
screens. Solving the case earns the lamp's second upgrade — a strength of 3, which lifts the
wall of Development — and the policy tab gets pages of three blocks.

**Approach:** five code tasks, each green on its own. The words (T1). The colleague: a fifth
shirt, a route written at the end of the map, an everyday saying (T2) — from here the floor
has 23 movers. The traces of HR on the floor and the region's name in the journal (T3) —
from here the state has eighteen traces. Pages on the policy tab (T4) — nothing shows yet,
because three cases give one page. The case itself: the fourth entry of `CASES`, the
intern's hints and the line of the upgrade (T5) — the tables are all that changes; the rules
of 0024, 0025, 0029, 0033 and 0034 read them. Then the documents (T6), the full check with
the container (T7), the walk (T8) and the pull request (T9).

**How this plan was checked:** the code and the tests of Tasks 1 to 5 were run once as a
prototype on 2026-11-19 and then replayed task by task, each task's tests before its code:
they failed as the steps say, and after each of the five tasks typecheck and Biome were clean
and the unit tests green — 1701, 1708, 1719, 1725 and 1755 tests (1700 before). The
blocks of this file, applied in order to a clean tree, with `npm run gen-sprites` after the
shirts and `npm run gen-floor` after each change of the layout, gave the prototype's files;
the generated `person-5.png` has the SHA-256
`1e5e90919552c63eebc4d6b7a4db5d7c1fe61869ef950c42d902db09262cfcbb` and the generated
`floor.tmj` `5951ec7d3e4e3bd141acf15459d297d76b3464cd2ce7a603f55d22d33f6257d0`. `npm run check`
with the build passed on the whole prototype, and the smoke spec passed twice against a dev

## Global constraints

- INV-1: the shape of the state does not change. The movers get a 23rd entry, the traces
  three more; the page of the journal (0038) now counts on the policy tab too.
- INV-2: `game/journal` imports `policyBlocks` from `game/cases`; nothing of `render/`.
- INV-4: eleven new keys and one changed page in both tables; code holds keys.
- INV-6: `public/sprites/person-5.png` is generated by `npm run gen-sprites`, never edited by
  hand. Its shirt is `#feae34`, a colour of Endesga 32 that no other figure wears.
- INV-7: no coordinate of the route or of a trace is in `src/`. `tools/floor-layout.ts`
  holds them, and `public/maps/floor.tmj` is generated by `npm run gen-floor`.
- **Nothing before the new objects moves.** The route's four points are written at the end
  of the file, ids 141 to 144, and the three traces after them, ids 145 to 147;
  `nextobjectid` is 148. Two tests hold the objects before them to recorded digests. So the
  colleague of HR is the 23rd mover, and the traces of HR have the indices 15 to 17.
- **The two recorded digests of 600 steps** (`RECORDED` in `tests/unit/journal.test.ts` and
  in `tests/unit/help.test.ts`) are never recorded again. From Task 2 on their projection
  hashes the first 22 movers, as they were recorded — criterion 20.
- **The world data does not change.** `UPGRADES` has held `filter`, earned in HR, since
  0014; the rule of 0029 earns it. This feature adds its line of notice and nothing else:
  no look for the filter, no hidden trace, no hidden path.
- **The order of the cases is the order of `CASES`:** Sales, Marketing, Support, HR. The
  intern asks them in that order, and the close (0034) follows the last.
- **A colleague in reach takes a press of `E` first.** Tests on the floor that press `E` for
  something else take the movers out of the state.
- **Glyphs:** a space is not drawn; the frame of a character is its code minus 32.
- A local helper in a test must not be named `after`, `before`, `beforeEach` or `afterEach`.
- What is out of the spec is not built: no species of HR, no works council, nothing the
  filter shows, no further device or colleague in HR, no pages on the cases tab, no sound.
- No `any`, no `@ts-ignore`. Commits: imperative subject, a body that says why, signed (run
  `git commit` outside the sandbox; if signing fails, retry once, then stop and ask — never
  pass `--no-gpg-sign`), ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Format with
  `npx biome check --write <files>` before `npm run check`. Do not stop a dev server that is
  not yours. Push nothing before the walk has passed.
- The numbers, verbatim from the spec: the route (6, 5, 300) · (11, 5, 0) · (11, 13, 180) ·
  (11, 5, 0); the shirt `#feae34`; the traces on the cells (3, 3), (14, 3) and (3, 10);
  pages of three blocks; the mark of the page right-aligned to x = 304 on the line y = 26;
